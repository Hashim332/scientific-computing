# Scientific Computing

This repository contains a series of Python-based exercises, simulations, and projects exploring topics in **scientific computing**.  
It is organised into weekly modules, each focusing on a specific computational method or applied problem in physics, mathematics, and engineering.

---

## 📂 Repository Structure

### Week-by-Week Modules
- **week_1** – Introduction to scientific computing concepts and Python fundamentals.
- **week_2_lunar_lander** – Simulating spacecraft motion using physics-based modelling.
- **week_3_stochastic_methods** – Random processes, Monte Carlo simulations, and probabilistic modelling.
- **week_4_odes** – Solving ordinary differential equations numerically.
- **week_5_signal_processing** – Fourier transforms, filtering, and time-series analysis.
- **week_6_optimisation** – Numerical optimisation methods for scientific problems.
- **week_7_final_project** – Capstone project applying multiple techniques learned in previous weeks.

---

## 🛠 Technologies Used
- **Python 3.x**
- [NumPy](https://numpy.org/) – Numerical computing
- [SciPy](https://scipy.org/) – Advanced scientific algorithms
- [Matplotlib](https://matplotlib.org/) – Visualisation
- [Pandas](https://pandas.pydata.org/) _(if applicable)_ – Data analysis
- [Jupyter Notebook](https://jupyter.org/) – Interactive exploration
